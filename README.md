# 🍽️ Gastro Review

## 📌 Descrição do Projeto
Este projeto consiste no desenvolvimento de um site de avaliação de restaurantes, criado como trabalho da disciplina de Banco de Dados.  
O sistema permite que os usuários avaliem restaurantes utilizando uma escala de notas de **1 a 5**, de acordo com sua experiência.

O objetivo principal é aplicar conceitos fundamentais de banco de dados, como modelagem, relacionamento entre tabelas, armazenamento de dados e consultas SQL, integrados a uma aplicação web.

---

## 🎯 Objetivos
- Criar um banco de dados para armazenar informações de restaurantes
- Permitir avaliações com notas de 1 a 5
- Calcular a média das avaliações de cada restaurante
- Aplicar conceitos de chave primária e chave estrangeira

---

## 🧩 Funcionalidades
- Cadastro de restaurantes
- Listagem de restaurantes
- Avaliação de restaurantes com notas de 1 a 5
- Exibição da média de avaliações
- Armazenamento das avaliações no banco de dados

---

## 🗄️ Estrutura do Banco de Dados
O banco de dados é composto pelas seguintes tabelas:

- **Restaurante**: armazena as informações dos restaurantes
- **Avaliação**: armazena as avaliações realizadas pelos usuários

As tabelas se relacionam por meio de chaves estrangeiras, garantindo a integridade dos dados.

---

## 🛠️ Tecnologias Utilizadas
- Banco de Dados: MySQL
- Frontend: HTML, CSS e JavaScript
- Backend: Php

---

## 📚 Conclusão
Este projeto permite aplicar na prática os conceitos estudados na disciplina de Banco de Dados, simulando um sistema real de avaliação de restaurantes e reforçando o uso de modelagem e consultas ao banco de dados.
